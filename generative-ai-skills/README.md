# Learn Prompt Engineering Fundamentals

## What I Did
Practiced prompt engineering using a free AI tool by testing an initial prompt, refining it into a more specific prompt, and documenting the prompts, outputs, and improvements in this README.

## Prompt Comparison

### 1. Initial Prompt
> "Explain prompt engineering."

**Output Summary:**
* Gave a general, broad definition of prompt engineering and a few high-level tips.

### 2. Improved Prompt
> "Act as a beginner-friendly tutor. Explain prompt engineering in 4 short bullet points for a computer science student, with one practical example of improving a vague prompt."

**Output Summary:**
* Provided a shorter, more structured, student-focused explanation with a concrete before-and-after example.

## What Changed When I Improved the Prompt
* **Tone & Audience:** Adding a role and target audience made the explanation match a student level instead of a generic overview.
* **Format & Length:** Specifying bullet points and an example made the response clearer, more concise, and immediately usable.

* ## what I learned
* clear instructions,context,role/format constraints,and examples significantly improve AI output quality compared to vague prompts.

## What I Learned
Clear instructions, context, role/format constraints, and examples significantly improve AI output quality compared to vague prompts.
