# Create Resume Generation prompts

**Track:** Generative AI & Prompt Engineering — Prompting for Coding (Training Trains Internship)  
**Lesson:** 19 of 133 | Level 1

## Overview
This folder covers practical prompt engineering techniques for using AI to generate, explain, and debug code—as well as structuring prompts clearly for targeted outputs like resume generation and technical workflows.

## Key Concepts & Best Practices
* **Clear Specifications:** Clearly state the programming language, framework, expected inputs, desired outputs, and constraints.
* **Explanations & Tests:** Request clear explanations alongside generated code, plus unit tests to verify small pieces of logic.
* **Effective Debugging:** Share exact error messages and relevant code snippets rather than vague problem descriptions.
* **Code Review & Safety:** Treat AI as a pair programmer—review, run, and test all generated code yourself, and never paste secrets, API keys, or private credentials into prompts.

## Key Terms
* **Code Generation:** Using AI to draft code from clear requirements.
* **Debugging Prompt:** Sharing error logs and context so AI can help pinpoint issues.
* **Unit Tests:** Small, focused tests that check individual functions or code blocks.
* **Code Review:** Inspecting code for correctness, readability, edge cases, and quality.

## What I Learned
* Writing structured prompts with clear boundaries and constraints produces much more reliable code and outputs than open-ended requests.
* AI speeds up drafting and troubleshooting, but ownership of code quality, testing, and security always stays with the developer.
