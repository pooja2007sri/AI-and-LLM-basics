# Write Structured Prompts

## Task Overview
Practiced writing structured prompts using clear sections (Role, Context, Task, Constraints, and Output Format) and delimiters in a free AI tool (ChatGPT / Gemini) to get predictable, well-organized outputs.

---

## Prompt 1: Structured Study Plan Generator
- **Unstructured Prompt:** Give me a study plan for data structures.
- **Output:** Start with arrays and linked lists, then learn stacks, queues, trees, and graphs. Practice coding problems every day and revise before exams.

- **Structured Prompt:**
  ```text
  ### Role
  You are an experienced computer science tutor.

  ### Task
  Create a 4-day revision plan for Data Structures.

  ### Constraints
  - Cover Arrays, Linked Lists, Stacks/Queues, and Trees.
  - Keep each day's plan under 2 short lines.
  - Format the output as a clean Markdown table with columns: Day, Topic, and Key Focus.
