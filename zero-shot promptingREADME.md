# Use Zero-Shot Prompting

## What I Did
I practiced zero-shot prompting without giving examples in a free AI tool and refined the prompt with clear constraints to improve the output.

## Prompt
- **Initial Prompt:** Explain what a stack is in data structures.
- **Output:** A stack is a linear data structure following LIFO where items are pushed and popped from the top.

- **Improved Prompt:** Explain what a stack is in data structures for a beginner in 3 short bullet points with one real-world example.
- **Output:**
  - Uses LIFO (Last In, First Out) order.
  - Like a stack of plates where you take the top one first.
  - Supports push and pop operations.

## What Changed
Added audience level, bullet limit, and a real-world example while keeping it zero-shot (no examples).

## What I Learned
Clear instructions and format constraints give cleaner outputs even without examples.
