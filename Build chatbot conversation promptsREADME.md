# Build chatbot conversation prompts

**Track:** Natural Language Processing — Building NLP applications (Training Trains Internship)  
**Lesson:** 21 of 133 | Level 1

## Overview
This folder documents my notes and learnings for **Build chatbot conversation prompts**, covering how to design, evaluate, secure, and monitor NLP-powered features responsibly.

## Key Concepts & Best Practices
* **Common NLP Applications:** Chatbots, semantic search, document Q&A, and feedback analysis.
* **Model Selection:** Choose between managed APIs and open models based on cost, privacy, and control requirements.
* **Evaluation & Oversight:** Validate outputs systematically using structured test sets alongside human review.
* **Security & Privacy:** Protect applications against prompt injection attacks and prevent sensitive data leaks.
* **Production Monitoring:** Continuously track response quality, latency, and operational cost once deployed.

## Key Terms
* **Chatbot:** A conversational application that understands user queries and responds naturally.
* **Semantic Search:** Searching content based on meaning and intent rather than exact keyword matches.
* **Prompt Injection:** Malicious instructions hidden inside user input to manipulate model behavior.
* **Human Review:** Manual inspection of model outputs to ensure accuracy, safety, and quality.

## What I Learned
* Building effective NLP and chatbot workflows goes beyond writing a good prompt—it requires proper evaluation, guardrails against prompt injection, and continuous monitoring.
* Treating an NLP assistant like a well-trained receptionist—knowing how to answer clearly and when to escalate—keeps user interactions reliable and safe.
