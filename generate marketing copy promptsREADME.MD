# Generate Marketing Copy Prompts

## Goal
Build structured prompts that generate persuasive, audience-targeted marketing copy while ensuring outputs stay clear, accurate, and aligned with reviewer criteria.

## What I Did
- Defined a one-line goal and reviewer checklist before drafting any marketing copy prompts.
- Built reusable prompts specifying target audience, value proposition, brand tone, call-to-action (CTA), and format constraints (such as ad copy, landing page hooks, and email taglines).
- Tested prompts with normal product inputs and unusual/edge inputs (like vague product details, strict character limits, or conflicting tones) and refined the constraints where outputs broke or sounded generic.
- Committed progress step by step in Git and documented everything in this dedicated folder.

## How to Run or Read
1. Open the prompt files in this folder and copy a prompt into your LLM interface.
2. Replace placeholder inputs (product/service, target audience, key benefit, tone, and CTA) with your test scenario.
3. Evaluate the generated marketing copy against the reviewer checklist and edge-case notes in this folder.

## What I Learned
- Defining the audience, core pain point, and desired action up front prevents generic sales buzzwords.
- Testing unusual inputs—like tight character limits or minimal product info—reveals where prompts need stricter structure and fallback rules.
- Incremental Git commits make it easy to track how each prompt tweak improves clarity and conversion focus.
