# Develop Coding Prompts

## What I Did
- Completed Lesson 12 (*Develop coding prompts*) under *Generative AI & Prompt Engineering: Prompting for coding* (`trainingtrains.com`).
- Practiced specifying language, framework, inputs, outputs, and constraints when prompting AI to write, explain, and debug code.
- Focused on asking for explanations and unit tests, sharing error messages and relevant code for debugging, and reviewing/testing all generated code without sharing secrets or private keys.

## What I Learned
- AI acts like a pair programmer, while I remain responsible for reviewing, testing, and owning the final code.
- Clear constraints, error details, and unit tests make code generation and debugging much more reliable.
- Keeping secrets and private keys out of prompts is essential for safe AI-assisted development.
